## 🔬 Research & Projects

### 🤖 Vision-Based Robot Navigation | Embedded AI Research
Exploring vision-based robot navigation and intelligent mapping using Raspberry Pi and NVIDIA Jetson Nano.

- Camera-based environmental perception.
- Visual place recognition and mapping.
- Path planning and navigation logic.
- Exploring autonomous navigation without LiDAR or QR-based localization.

### 📡 Doppler-Based Pedestrian Safety & Vehicle Speed Monitoring
Research internship project at **Rajiv Gandhi Institute of Petroleum Technology (RGIPT), Jais**.

- HB100 X-band Doppler Radar with ESP32.
- Analog signal conditioning and signal acquisition.
- FFT-based Doppler frequency extraction.
- Motion detection and vehicle speed estimation.

### 🫁 UWB Radar-Based Physiological Signal Analysis
Exploring contactless physiological monitoring using UWB radar data.

- Respiration signal extraction.
- Signal processing and frequency-domain analysis.
- Cross-correlation and phase analysis.
- Experimental analysis of radar recordings.

Developed an end-to-end machine learning pipeline for used car price prediction.

- Data preprocessing and feature engineering.
- Regression model experimentation.
- Model evaluation and performance comparison.
